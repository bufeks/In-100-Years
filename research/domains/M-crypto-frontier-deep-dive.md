## Bitcoin が Bitcoin だった 5 条件（スクリーニング軸）

## 4 セグメント統合の投資戦略（Q2 短期資産の中核）

**あなたの目的関数（数年で ¥30M+/年 income、10-20% 分散、Q2 象限）に対する配分例**：

```
Q2 象限予算 ¥3M（想定・変更可）
├─ M2 RWA トークン化 ¥1.2M（40%）─ 最も制度化に近い、下振れ小
│    ├─ ONDO $3,000（1/3）
│    ├─ BUIDL/OUSG $3,000（1/3）
│    └─ COIN 株 $3,000（1/3）
├─ M1 Bitcoin L2 ¥900K（30%）─ BTC 上乗せの非対称
│    ├─ STX $3,000（1/2）
│    └─ Babylon Phase 2 参加 0.05 BTC 相当（1/2）
├─ M3 ZK インフラ ¥600K（20%）─ 最大非対称・逆張り
│    ├─ STRK $2,000（1/2）
│    └─ ZK / Scroll エアドロップハンティング $2,000（1/2）
└─ M4 Prediction Markets ¥300K（10%）─ 情報優位ベット
     └─ Polymarket USDC 少額分散
```

**期待リターン試算**（5-10 年）：
- 中央値：2-3x（¥6-9M）
- 中央値ケースの内訳：M2 が着実に 3x、M1 が 5x、M3 が 5-10x、M4 が横ばい
- 上振れ：10-30x（¥30-90M） ─ M1/M3 が 50-100x 化した場合
- 下振れ：0.3-0.5x（¥1-1.5M） ─ crypto 全体崩壊・SEC 規制強化
