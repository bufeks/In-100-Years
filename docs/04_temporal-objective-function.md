# 時間軸別の目的関数（4 象限マトリクス）

`docs/01`（市場価値・7 軸）と `docs/03`（個人着手・5 軸）だけでは、「**何を、いつ、どんな目的で狙うか**」が決まらない。目的関数を明示するために、**時間軸 × 収益タイプ**の 2×2 マトリクスをこのレイヤーで管理する。

---

## なぜ必要か

同じ 22 アイデアでも、投資家の目的で優先順位は劇的に変わる：

- 「**数年で ¥30M+/年 income**」を狙う人にとって：**Q1 が主戦力**、他は雑音。
- 「**100 年で資産を残したい**」人にとって：**Q4 が主戦力**、Q1 は消費的。
- 「**余剰資金を分散運用**」したい人にとって：Q2 が主戦力。
- 「**20 年で経済的自立**」を目指す人にとって：Q3 の積み上げが主戦力。

100 年統合スコアだけを見て動くと、**自分の目的関数と合わないポジション**を取ってしまう。この doc で目的関数を先に決めて、対応する象限に集中投下する規律を持つ。

---

## 2 つの新しい軸

### 軸 1：時間軸（Time-to-first-cashflow / return）

| 帯 | 定義 | 典型 |
|---|---|---|
| **短期** | 1–5 年で最初のキャッシュフロー／リターン | 事業起業、SaaS、投資、M&A |
| **長期** | 5–100 年スパンで花開く | 土地保有、規格、IP、インフラ |

### 軸 2：収益タイプ

| タイプ | 定義 | 単位 |
|---|---|---|
| **Income** | 継続的キャッシュフロー | ¥／年 |
| **資産** | 純資産の appreciation（塊） | ¥ |

## 使い分けのルール

1. **目的関数を先に決める** — 「数年で ¥30M/年 income」なのか、「20 年で経済自立」なのか、「100 年で子孫資産」なのか。
2. **主戦力は 1 象限に集中投下** — 4 象限に均等分散は wrong。時間・資本・意識をメイン象限へ 70-80%。
3. **副戦力で他象限を保険的に張る** — 20-30% で他象限を薄く。
4. **象限をまたぐアイデアは複層収益**として理解 — 例：0025 空き家は Q3（賃貸 income）と Q4（土地 appreciation）の両方に位置。

## kiCk 系ユーザーの目的関数例（数年で ¥30M+/年）

**主戦力（70-80%）**：Q1 の 3 テーマに集中
- **0022 ポスト AI クリエイティブ AGY**：kiCk のポジション活用（最速、1-3 年）
- **0024 クリエイター IP カストディアン**：kiCk のタレント事業拡張（日本市場空白）
- **0026 後継者難 M&A**：レバレッジ活用（日本政策金融公庫 5-10x）

**副戦力（10-20%）**：Q2 で余剰資金を分散
- **0013 ポスト公開市場**：BLK／SCHW／HOOD／ONDO の組み合わせ

**賩け（5-10%）**：Q1 の 0007-ε／0019 のいずれかで SaaS を副業立ち上げ（100M-1B upside）

**保留**：Q3／Q4 は数年後、Q1 で結果が出た後に着手（0025 Kabukicho は「老後の保険」として保有余力ができた時）

## 目的関数変更時の再ランキング

目的関数が変わったら、この doc に立ち返って主戦力象限を切り替える。100 年統合スコア（`INDEX.md`）は世界全体の観測値として不変だが、**個人にとっての優先順位はここで決まる**。
